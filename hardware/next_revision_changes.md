# C-Logger 次版 変更一覧（案）

目的:
1. 省コスト化（JLCPCB の Basic 部品化、K-Logger との部品共通化）
2. USB 給電での操作（K-Logger と同じ電源切り替え回路）
3. USB コネクタを表面実装 micro-B から Type-C（シェル足スルーホール）へ
4. 同じ基板で CO2 なし（温湿度のみ）版を作れるようにする

前提:
- 電池は CR2032 のまま
- USB 給電中の計測（記録）は考えない。USB 接続中は操作と、動作確認のための表示のみ
- BOM 案: `hardware/BOM_next_draft.xlsx`（JLCPCB 部品番号・100個時の単価・現行からの変更点）

部品代（1台、100台製造時、2026-10-22 時点の JLCPCB 単価）:

| 版 | 部品代 | Extended 種類数（注文ごとに約 $3/種類） |
|---|---|---|
| CO2 あり | 約 $16.6 | 9 |
| CO2 なし（温湿度のみ） | 約 $7.2 | 8 |

最大の部品は STCC4（$9.41）。次いで AVR64DU32（$2.96）、W25Q128JVSIQ（$1.82）、SHT40（$1.18）。

## 1. 回路図の変更

### 1-1. USB コネクタと保護（K-Logger と同じ）
- J1: micro-B（UJ2-MIBH-G-SMT-TR）→ **TYPE-C 16PIN 2MD(073)（C2765186）**
  - DP1/DP2 → DP、DN1/DN2 → DN にまとめる
  - CC1、CC2 をそれぞれ 5.0 kΩ で GND へ: **RN2（10k×4）を 2 個並列 ×2 系統に転用**（現行 RN2 は VBUS 分圧なので用途変更）
  - シェル（SHIELD）は GND へ
- **ESD 保護 USBLC6-2SC6 互換（C2827654）を追加**: DM/DP をピン 1↔6 / 3↔4 で通し、ピン 5=VBUS、ピン 2=GND

### 1-2. USB 給電の電源切り替え（K-Logger と同じ）
現行は電池 → 昇圧（TPS61021A）のみで、USB 接続時も電池から給電していた。

- **LDO XC6206P332MR-G（C5446）を追加**: VBUS → 3.3V。入出力に 1 µF ×2
- **ショットキー B5819W（C8598）を追加**: LDO 出力 → 昇圧 IC の VIN（ダイオード OR）
- **Pch MOSFET AO3415A（C133233）を追加**: 電池＋ → 昇圧 IC の VIN。G=VBUS、G と GND の間に 100 kΩ
  - USB 接続中（G=5V）は電池を切り離す。USB 非接続時（G=0V）はオン。電池の逆接保護も兼ねる
  - 向き: D=電池＋、S=昇圧 IC の VIN（ボディダイオードが電池→VIN の向き）
- 電池電圧の測定（PD3）は電池＋（MOSFET の手前）のまま

### 1-3. VBUS 検出
- 現行: RN2（10k/10k）で VBUS 5V → 2.5V を PF4 へ。VDD 3.3V での VIH（0.7×VDD = 2.31V）に対して余裕が小さい
- 変更: **22 kΩ / 47 kΩ（3.4V）**に（K-Logger と同じ）。接続先は PF4 のままで可（AVR DU は全ピンが非同期検出なので STANDBY から起床できる）

### 1-4. CO2 なし版のためのジャンパ
- 現行: SHT40 は STCC4 のセンサ用 I2C（SDA_C/SCL_C）だけにつながっていて、STCC4 を載せないとマイコンから読めない
- 変更: **0 Ω ジャンパを 2 個追加（R7: SDA↔SDA_C、R8: SCL↔SCL_C）**
  - CO2 あり版: STCC4 実装、**R7/R8 未実装**
  - CO2 なし版: STCC4 未実装、**R7/R8 実装** → SHT40 がマイコンの I2C に直結（プルアップは RN1 が効く）
  - **両方を同時に実装しないこと**（STCC4 は SDA_C/SCL_C 側で I2C の親として動くので、親が 2 つになり通信できなくなる）
- 参考（STCC4 データシート）: SDA_C/SCL_C には 10 kΩ のプルアップが内蔵されている。SHT4x を近くに置く場合、追加のプルアップは推奨されない。SDA_C/SCL_C を使わない場合も浮いたパッドにはんだ付けする

### 1-5. デカップリングの追加・修正
- VUSB（6 番）: 100 nF → **470 nF**（データシートの CVUSB。K-Logger と同じ）
- VDD_2（18 番）に **100 nF を追加**（現行は VDD 28 番のみ）
- **SHT40/STCC4 に共用で 100 nF（C6）、W25Q に 100 nF（C8）を追加**（現行は無し）

### 1-7. 100 µF（C7）
- 元は「USB 接続時の電流がボタン電池から賄えない」対策。次版は USB 給電になるので、その目的では不要
- ただしボタン電池は内部抵抗が大きく、フラッシュ書き込み（〜25 mA）や STCC4（ピーク 4.2 mA）の瞬間電流で電圧が落ちる。**BOM 案では残している**（JLC Basic で $0.10）。試作で電圧降下を測ってから削除を検討

## 2. 基板（レイアウト）の注意
- **SHT40 は熱源から離す**: USB 接続中は LDO とマイコンが発熱する。表示用でも値がずれると見栄えが悪いので、SHT40 は基板の端、LDO・マイコン・昇圧 IC から遠い位置に置き、周囲にスリット（ミリング）を入れて熱を遮る
- **Type-C**: シェル足の長穴は PTH 指定（K-Logger と同じ。`klogger/hardware/fab/README.md` 参照）。基板端からのはみ出し量も K-Logger に合わせる
- **R7/R8 は STCC4 の近く**に置き、SDA_C/SCL_C の配線を短く
- **シルク**: 「Popolo」ロゴ（`popolo3/assets/logo/popolo_silk_2.5mm.svg`）、製品名「C-Logger」、「Togashi Research Institute LLC」、版表記。CO2 あり/なしを区別するなら、シルクに「CO2」欄を設けて、実装版でチェックを入れるなどの方法がある
- フラッシュが SOIC-8（208mil）になり、WSON より面積が増える

## 3. ファームウェアの変更
- **USB/電池のモード管理**: K-Logger と同じ（USB 挿入で USB 通信モード、抜去で待機、記録中の抜去は記録継続。VBUS 検出ピンの割り込みで起床）
- **センサの自動判定**: 起動時に STCC4（0x64）の応答を確認
  - 応答あり → 現行どおり STCC4 経由で CO2・温湿度を取得
  - 応答なし → SHT40（0x44）を直接読む（温湿度のみ）。記録データの CO2 は「なし」として扱い、PC ツールでも CO2 列を出さない
- **フラッシュ**: W25Q64 → W25Q128（容量 2 倍、24bit アドレスの範囲内。K-Logger のドライバを流用）
- **ピン割り当て**（2026-10-23 回路図）: VBAT=PF5、VBUS 検出=PF2（K-Logger と同じ）、**LED=PD5、SW=PD6、フラッシュ CS=PA1**（K-Logger とは異なる）、I2C=PA2/PA3、SPI=PA4/PA5/PA6。現行 C-Logger（VBAT=PD3、VUSB=PF4）から変わる。MCC のピン設定を作り直す
- **電池電圧の ADC**: CR2032（〜3.2V）は K-Logger の基準電圧 2.048V を超えるので、**基準電圧を VDD（3.3V）にする**（MCC）
- **LED**: ピンは同じ（PC3）。色が変わるだけ
- USB のエラッタ対策（SET_LINE_CODING の偶数アドレス化）は対応済み
