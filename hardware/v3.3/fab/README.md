# C-Logger 基板 3.3 製造データ（JLCPCB入稿用）

基板バージョン: **3.3**（シルク表記「Version 3.3」）。温湿度＋加速度。3.2 の昇圧 IC を **TPS63900**（昇降圧、自己消費 75nA）に替えて、電池の持ちを延ばした版。ほかの回路は 3.2 と同じ。

| `JLCPCB_CPL_v3.3.xlsx` | 入稿用の部品配置データ（列: Designator / Mid X / Mid Y / Layer / Rotation）。Fusion の部品配置出力（`PnP_C-Logger_v3.3_front.txt` / `back.txt`）から、UPDI のテストパッドを除いて作った。BOM と参照記号が全数一致（37個） |
| `clogger_v3.3_gerber.zip` | ガーバー一式（Fusion Electronics 出力、2層、26 × 26 mm、ドリル `.XLN` とガーバージョブを含む）。裏面のペースト層（`.GBP`）は空 |

- 設計データ: `hardware/v3.3/pcb/clogger_v3.3.f3z`、回路図: `hardware/v3.3/pcb/clogger_v3.3_schematic.pdf`、外観: `hardware/v3.3/pcb/clogger_v3.3_top.png` / `_bottom.png`
- U6 のデータシート: `hardware/datasheet/U6_v3.3.pdf`（TPS63900、SLVSET3D）

## 目的

CO2なし版で、1分間隔・CR2032 1個で1年以上記録できるようにする。

- 3.2 の記録中の電流は約38〜41uA で、そのうち約22uA が昇圧 IC（TPS61021A）の自己消費（約17uA）と帰還抵抗 R5/R6（約5uA）。
- TPS63900 は自己消費 75nA typ。出力電圧は CFG ピンの抵抗を起動時に一度読んで決めるので、帰還抵抗の電流もなくなる。
- 見込み: 平均 約17uA（加速度計の分は見積もりで +5uA、合わせて約22uA）。CR2032 を 200mAh と見て、約12〜16か月。実測で確かめる。

### U6 の結線

データシート 図8-1 の例（SEL = High、CFG1 = 36.5kΩ）は、36.5kΩ が JLC で手に入らないため使わない。SEL = Low にして、CFG3 で 3.3V を選ぶ（表7-3）。

| ピン | 番号 | つなぎ先 |
|---|---|---|
| EN | 1 | VIN（直結） |
| SEL | 2 | GND（直結）。Low で VO(1) = CFG3 の設定を使う |
| CFG1 | 3 | GND（直結）。VO(2) = 1.8V（SEL が Low なので使われない） |
| CFG2 | 4 | GND（直結）。入力電流の上限なし |
| CFG3 | 5 | R5 16kΩ → GND（VO(1) = 3.3V） |
| VOUT | 6 | +3V3、C12・C13 |
| L2 | 7 | L1 |
| GND | 8 | GND |
| L1 | 9 | L1 |
| VIN | 10 | VIN（Q1 の出力と D1 のカソード）、C11・C14 |
| TP（裏面パッド） | 11 | GND。パッドの下にビア4本 |

- CFG ピンはどれも開放にしない（データシート 表5-1）。CFG の抵抗は起動時に一度読むだけで、そのあとは電流が流れない。

### 16kΩ で足りるか

- データシート 6.5 では、R2D 設定 #11（3.3V）の抵抗は 16.2kΩ の −3%〜+3%、つまり 15.71〜16.69kΩ。
- 16kΩ ±1% は 15.84〜16.16kΩ。温度係数 ±100ppm/℃ で −40〜85℃ なら、さらに ±0.65% で 15.74〜16.27kΩ。範囲には入る（下側の余裕は約0.2%）。
- 隣の設定は #10 が 13.3kΩ（3.0V）、#12 が 20.5kΩ（3.6V）。読み違えても部品を壊す電圧にはならない（SHT40 の上限は 3.6V）。

### 入力電流の上限（今は「上限なし」）

CFG2 を抵抗で GND に落とすと、入力電流の平均に上限をかけられる（CFG1 = GND のとき、表7-2）。

| CFG2 | 0Ω | 511Ω | 1.15k | 1.87k | 2.74k | 3.83k | 5.11k | 6.49k |
|---|---|---|---|---|---|---|---|---|
| 上限 | なし | 100mA | 50mA | 25mA | 10mA | 5mA | 2.5mA | 1mA |

フラッシュの書き込み（約25mA）と USB 動作中を考えると、25mA 以下は足りない。電池の電圧降下を和らげたいなら、50mA か 100mA を試す（基板の改修が要る）。

## 発注時の指定

3.2 と同じ（`hardware/v3.1/fab/README.md` の「発注時の指定」）: 表面処理 ENIG、板厚 1.2 mm、J1 の長穴は PTH、U1 は Global Sourcing、BT1 は裏面のスルーホール部品。JLC のプレビューで **U8 と U6 の向きと1番ピンの位置**を確かめる。

- 電池のマイナス接点（BT1 の Ø14 パッド）と UPDI のパッドは、3.2 と同じくステンシルをオフにしている。
- J1（USB-C）の位置は、3.2 と同じく部品の原点 **13.0, 2.9 mm** に直している（Fusion の出力は 4.20 mm）。

## 試作で確かめること

1. 電池を入れたとき・USB を挿したとき・抜いたときに 3.3V がきちんと立ち上がるか（EN を VIN に直結している。データシートの例では EN はシステムから制御）。
2. フラッシュ書き込み時の電圧降下（電池が減ったとき、2.2V 付近）。
3. 待機と記録中の電流。リポジトリの README の「消費電流の実測」と同じ測り方で 3.2 と比べ、Web アプリの電池の持ちの定数（`batteryLifeSec` の 33uA）を直す。
4. TPS63900 は VIN が約1.65V を下回ると止まる（立ち上がり 1.75V）。ファームウェアの電池切れの判定のほうが先に来るか。
