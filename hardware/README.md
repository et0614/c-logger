# C-Logger ハードウェア

| 版 | 用途 | センサ | フォルダ |
|---|---|---|---|
| 3.2 | 持ち歩き用（主力） | 温湿度（SHT40）＋ 加速度（SC7A20H） | `v3.2/` |
| 3.1 | CO2あり版 | CO2・温湿度（STCC4＋SHT40）。R7・R8 に 0Ω を載せれば温湿度のみにもなる | `v3.1/` |

ファームウェアは1つで、起動時に載っているセンサを調べて動く。

```
BOM.xlsx       設計用の部品表（部品の選定理由など）
lib/           自作の部品ライブラリ（SC7A20H の .lbr・3D モデル .stp と、その生成スクリプト）
datasheet/     主要部品のデータシート（ファイル名=参照記号）
enclosure/     ケース（上蓋）
v3.2/pcb/      Fusion の設計データ（.f3z）、回路図 PDF、外観
v3.2/fab/      JLCPCB 入稿データ（BOM・CPL・ガーバー）と README（3.1 からの変更点）
v3.1/pcb/      同上（3.1）
v3.1/fab/      同上（3.1。CO2あり版・なし版の BOM・CPL）と README（発注時の指定、版の履歴）
```
